# Elias Hasnaou — Portfolio

Personal portfolio presenting machine learning and research projects, skills and education.

## Files

- `dist/index.html`: page content and structure.
- `dist/styles.css`: responsive layout and light/dark themes.
- `dist/site.js`: theme preference.
- `vercel.json`: static deployment configuration.

## Deployment

Import this repository in Vercel. The framework preset is **Other**, no build command is required, and the output directory is `dist`. No environment variables or package installation are needed.

Push updates to the connected production branch (`main`) to publish them automatically.

## Editing

Edit the static files in `dist/`. Project descriptions distinguish research questions and planned evaluations from achieved results.
